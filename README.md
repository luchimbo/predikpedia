# 🚀 MiroModi v1 - Engine de Simulación Psicométrica B2B

## Misión
Simulación de alta fidelidad bajo el 'Protocolo Bill' para validación de negocios, pricing y viabilidad en LatAm y Europa. Su objetivo es sustituir grupos focales tradicionales mediante identidades densas inyectadas por IA.

## Arquitectura del Moat (Foso)
- **`core_logic.py`**: Interceptor de sinceridad y resistencia (Anti-alucinación y sycophancy). Evita matemáticamente que la IA sea "buenita" y apruebe gastos fuera de su realidad socioeconómica.
- **`locales.json`**: Cerebro multicultural. Almacena las directivas de miedos, referencias de precios y jerga obligatoria para adaptar la macroeconomía de los agentes (AR, ES, MX).
- **`methodology_v1.md`**: Manual fundacional y Registro de Propiedad Intelectual. Contiene la Matriz de Pesos Psicométricos OCEAN y las Reglas de Oro de resiliencia cognitiva (Loss aversion, Elasticidad Blue, O-T Correlación).

## Guía de Despegue
1. Para lanzar e inicializar una población, ejecuta el método Python de instanciación cruzada con cuotas. Ejs: `generate_population(num_agents=50, quotas_dict={"CMO":0.5, "Dueños":0.5}, locale="ES")`.
2. Para auditar los resultados de la identidad densa, utiliza el exportador y revisa siempre el CSV generado dentro de su entorno aislado en la carpeta `C:\MiroModi\Projects\[Nombre_del_Proyecto]\population_preview.csv`.

> **⚠️ Advertencia de Identidad:** Este entorno opera bajo el Watermarking de MiroModi de manera perimetral en su sistema base. Prohibido el uso de agentes complacientes.
